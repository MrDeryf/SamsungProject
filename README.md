# Атрибуция произведений искусства (Art Attribution AI)

Проект по определению атрибуции картин с помощью глубокого обучения. По изображению
картины модель предсказывает сразу три характеристики:

- **Художника** (`artist`)
- **Стиль** (`style`)
- **Эпоху** (`era`)

Предсказания сопровождаются визуализацией **Grad-CAM** — тепловой картой областей,
на которые модель опиралась при принятии решения.

## Архитектура модели

В основе — **гибридная многозадачная нейросеть**, объединяющая свёрточную сеть
(EfficientNet-B0) и трансформер (Swin Transformer Tiny). Реализованы два варианта
объединения признаков:

- **`ParallelHybridModel`** (по умолчанию) — изображение параллельно проходит через
  CNN и трансформер, их признаки конкатенируются и проходят через слой fusion.
- **`SequentialHybridModel`** — изображение проходит CNN → адаптер → трансформер
  последовательно.

Поверх общего эмбеддинга работают три независимые классифицирующие головы
(`MultiTaskHeads`) — по одной на каждую задачу.

```text
Изображение → [EfficientNet ‖ Swin] → Fusion → {Художник, Стиль, Эпоха}
```

## Установка

Проект использует [Poetry](https://python-poetry.org/) и Python 3.13+.

```bash
poetry install
```

## Запуск приложения

Streamlit-приложение ожидает обученные веса и маппинги классов:

- веса модели — `model_weights/model_final.pth`
- маппинги — `data/mappings/` (`id2artist.json`, `id2style.json`, `id2era.json`)

Запуск:

```bash
poetry run streamlit run app.py
```

После запуска откройте интерфейс в браузере, загрузите изображение картины
(`jpg`, `jpeg`, `png`) и получите предсказания художника, стиля и эпохи
вместе с Grad-CAM-визуализацией.

## Подготовка данных и обучение

Данные основаны на датасете
[Best Artworks of All Time](https://www.kaggle.com/datasets/ikarus777/best-artworks-of-all-time).
Конвейер подготовки (модуль `src/data_processing.py`) включает:

1. Сбор путей к изображениям и проверку на битые файлы (`analyze_dataset`).
2. Стратифицированное разбиение на train/val/test (`stratified_split`).
3. Извлечение стилей и эпох из метаданных художников и создание маппингов
   `artist2id` / `style2id` / `era2id` (`create_*_mappings`).

Основные параметры обучения (см. `src/config.py`):

| Параметр              | Значение                          |
|-----------------------|-----------------------------------|
| Размер изображения    | 224×224                           |
| CNN                   | `efficientnet_b0`                 |
| Трансформер           | `swin_tiny_patch4_window7_224`    |
| Размер эмбеддинга     | 96                                |
| Batch size            | 16                                |
| Эпохи                 | 50                                |
| Оптимизатор           | Adam, LR 1e-4                     |
| Scheduler             | cosine                            |
| Веса задач            | artist 1.0 / style 1.0 / era 1.0  |

> Пути в `src/config.py` по умолчанию настроены на окружение Kaggle
> (`/kaggle/input`, `/kaggle/working`). Для локального запуска замените
> `KAGGLE_INPUT` / `KAGGLE_WORKING` на абсолютные пути.
